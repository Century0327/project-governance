**关键区分（GPT 观察点）**："模型提到 LESSONS.md" ≠ "模型读了 LESSONS.md"。
- ① 主动读取 = 模型给出了文件实际内容、真实路径、或基于文件内容的回答（如引用 index 里的目录条目）。
- ② Skill 文本自带提及 = 模型只是"知道这些文件存在"（描述/映射表里写了），不等于加载阅读。
- 判断 token 成本看①，不看②。
